사용법

기사 문서

  • 쓰는 곳은 「제목:」「부제:」 줄, 「본문」 아래, 바이라인, 「캡션」 4줄뿐이다. 제목 2 스타일의 「본문」「캡션」「확인할 것」은 지우지 않는다(사이드바가 이 제목으로 위치를 찾는다).
  • 확인 안 된 문장은 형광펜. '확인할 것' 항목은 확인되면 취소선(Alt+Shift+5)이나 삭제.
  • 남의 문단은 제안 모드로 고친다. 단계마다 파일 → 버전 기록 → 이름 지정.

사이드바 설치 (문서 주인 1회)

  1. 기사 문서에서 확장 프로그램 → Apps Script
  2. Code.gs 내용을 이 폴더의 Code.gs로 바꾼다
  3. + → HTML → 이름 Sidebar → 이 폴더의 Sidebar.html 내용
  4. 저장 → 문서 새로고침 → 메뉴 「기사 IDE」 → 사이드바 열기(처음 한 번 권한 허용)

사이드바가 하는 일

  • 본문 글자 수(공백 포함) — 허용 1,720~1,850자. 476~479호 [대학]면 실측 줄 칸당 20.4자 기준
  • 단별 줄 예측 — 읽는 순서 1단 31, 2단 31, 3단 10, 4단 10, 5단 8줄(+바이라인 2줄)
  • 점검 — 바이라인 형식(첫 줄 도메인 전부, 이후 아이디@), △ 나열, 말줄임표, 19:38 중간 순위 오기, 캡션 ▲·한 줄 길이, 남은 형광펜, 제목 30자·부제 55자
  • 제출 빌드 — 03_제출에 「빌드 날짜-시각」 폴더: [대학] 제목 원고, 같은 이름 캡션 .txt, 사진 1~4 사본
